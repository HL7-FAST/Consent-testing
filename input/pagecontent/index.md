
### About This Guide

The Scalable Consent Management Testing Guide defines the testing artifacts used in the verification and validation implementations declaring conformance to and against the [Scalable Consent Management Implementation Guide](https://build.fhir.org/ig/HL7/fhir-consent-management/index.html).  

#### Actors

The following actors are part of the Scalable Consent Management IG for use in this testing guide:

* Admin Server: An application or product that receives and manages consent conformant to the Scalable Consent Management IG. This can be thought of as the server in a client-server interaction.
* Client: An application or product that sends to and queries consent data of a Consent Administrative Server conformant to the Scalable Consent Management IG. This can be thought of as the client in a client-server interaction.


#### Implementation Guide Artifacts

Please reference the [Scalable Consent Management IG FHIR Artifacts](https://build.fhir.org/ig/HL7/fhir-consent-management/artifacts.html) for complete definitions of expected behavior.
