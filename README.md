Scalable Consent Management Testing Guide

### Build Process

Builds are manually processed at this time.

#### TG Dependencies

The Scalable Consent Management TG depends on the Scalable Consent Management IG. Since this TG and the dependent IG are not currently published as HL7 FHIR guides, prior to building this Testing Guide the Implementation Guide must be locally built in order to populate the local FHIR package cache.

#### Find the rendered TG available at

https://wildfhir4.wildfhir.org/tg/fhir-consent-management-tg/index.html

#### For the qa build log see

https://wildfhir4.wildfhir.org/tg/fhir-consent-management-tg/qa.html
